
# Controle Mei

Projeto academico - Curso Superior Informatica para Negocios - 5º semestre Fatec Rio Preto.

Desenvolvimento de uma aplicação mobile utilizando Dart/Flutter com o objetivo de auxiliar microempreendedores individuais (MEI) no controle financeiro de seus negocios.


## Tech Stack

**Client:** Flutter

**Server:** Firebase
